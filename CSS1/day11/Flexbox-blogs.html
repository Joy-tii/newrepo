Understanding Flexbox in CSS: A Comprehensive Guide
Introduction Key concept Properties Flex-item

CSS Flexbox (short for "Flexible Box") is a powerful layout model that allows you to design complex and responsive layouts efficiently. It is particularly useful for aligning and distributing space among items in a container, even when their sizes are dynamic or unknown.
In this blog, we’ll explore the Flexbox model in detail, its key properties, and practical examples with code snippets to help you master it.

What is Flexbox?

Flexbox is a one-dimensional layout model, meaning it arranges items either in a row (horizontally) or a column (vertically). It simplifies tasks like centering items, creating equal spaces, or handling dynamic elements.
To start using Flexbox, set the display property of a container to flex or inline-flex:

.container {
display: flex; /* or inline-flex */
}

Key Concepts of Flexbox

1. Flex Container and Flex Items

  • Flex Container: The parent element where Flexbox is applied.
  • Flex Items: The child elements of the flex container.

2. Main Axis and Cross Axis

  • Main Axis: The primary axis along which flex items are placed. Defined by the flex-direction property.
  • Cross Axis: The perpendicular axis to the main axis.

Important Flexbox Properties

Flex Container Properties

1. flex-direction

Defines the direction of the main axis.

  • row (default): Items are placed from left to right.
  • row-reverse: Items are placed from right to left.
  • column: Items are placed from top to bottom.
  • column-reverse: Items are placed from bottom to top.

Example:


.container {
display: flex;
flex-direction: row; /* Try column, row-reverse, column-reverse */
}

2. justify-content

Aligns items along the main axis.

  • flex-start (default): Items align to the start of the container.
  • flex-end: Items align to the end of the container.
  • center: Items are centered along the main axis.
  • space-between: Space is distributed between items.
  • space-around: Space is distributed around items.
  • space-evenly: Equal space is distributed between and around items.

Example:


.container {
display: flex;
justify-content: center; /* Try flex-start, flex-end, space-between, etc. */
}

3. align-items

Aligns items along the cross axis.

  • stretch (default): Items stretch to fill the container.
  • flex-start: Items align to the start of the cross axis.
  • flex-end: Items align to the end of the cross axis.
  • center: Items are centered along the cross axis.
  • baseline: Items align along their baselines.

Example:


.container {
display: flex;
justify-content: center; /* Try flex-start, flex-end, space-between, etc. */
}

4. align-content

Aligns multiple rows of items when there’s extra space in the cross axis. Applicable only for multi-line containers.

  • stretch (default): Rows stretch to fill the container.
  • flex-start: Rows align to the start of the cross axis.
  • flex-end: Rows align to the end of the cross axis.
  • center: Rows are centered along the cross axis.
  • space-between, space-around, space-evenly: Similar to justify-content.

Example:


.container {
display: flex;
flex-wrap: wrap; /* Enables multi-line layout */
align-content: space-between; /* Try stretch, center, etc. */
}

5. flex-wrap

Controls whether items wrap onto multiple lines.

  • nowrap (default): Items do not wrap.
  • wrap: Items wrap onto the next line if needed.
  • wrap-reverse: Items wrap onto the next line in reverse order.

Example:


.container {
display: flex;
flex-wrap: wrap; /* Try nowrap, wrap-reverse */
}

Example:

.item {

}
.item-large {
flex: 2; /* Takes twice the space of .item */
}

.item {
flex-shrink: 1; /* Shrinks equally */
}
.item-small {

}

.item {
flex-basis: 100px; /* Fixed initial size */
}
.item-wide {
flex-basis: 200px; /* Larger initial size */
}
